# Репутация 2.0 — исследовательский прототип

Готовый статический проект для GitHub Pages. HTML, CSS и JavaScript, без сборки, Node.js и серверной части. Все шрифты, иконки и библиотека экспорта XLS находятся в проекте.

## Публикация

1. Создайте репозиторий GitHub с основной веткой `main`.
2. Загрузите **содержимое этой папки** в корень репозитория: `public/`, `.github/`, `.gitignore`, `README.md`. Не загружайте ZIP вместо файлов. При работе через файловый менеджер включите отображение скрытых папок, чтобы не пропустить `.github`.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Во вкладке **Actions** запустите **Publish prototype to GitHub Pages → Run workflow**. После настройки последующие изменения в `main` публикуются автоматически.
5. Ссылка появится в **Settings → Pages** и в результате workflow. Обычно это `https://USERNAME.github.io/REPOSITORY/`.

Если ветка называется иначе, измените `branches: [main]` в `.github/workflows/pages.yml`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Локальный просмотр

Из корня проекта при установленном Python 3:

```sh
python3 -m http.server 8000 --directory public
```

Откройте http://localhost:8000/ . Открывать `index.html` двойным кликом не рекомендуется: буфер обмена требует localhost или HTTPS.

## Файлы

- `public/index.html` — основной экран и меню.
- `public/app.js` — отзывы, карточки, фильтры, поиск и экспорт.
- `public/guest-profile.js` — профиль гостя для исследования.
- `public/style.css` — оформление.
- `public/assets/` — локальные иконки и шрифты.
- `public/vendor/` — SheetJS и её лицензия.
- `.github/workflows/pages.yml` — публикация только папки `public/`.

Все пути относительные: проект работает как в корне домена, так и по адресу репозитория. Профиль гостя открывается через `?view=guest&id=35` в соседней вкладке.

## Сценарий исследования

Введите «Холодно в комнате» и нажмите кнопку поиска справа или Enter. Найдётся отзыв Сергея Лапушкина от 24 ноября 2026: проживание 23–30 ноября, статус «Проживает сейчас». Из карточки доступен профиль гостя. Перед ним в списке находятся отзывы от 26, 27 и 28 ноября.

Демонстрационная дата прототипа — 2 декабря 2026. Состояние, ответы и фильтры сохраняются в localStorage браузера. Кнопка «Начать заново» восстанавливает исходные данные для следующего участника. У каждого браузера своё состояние; данные не синхронизируются между участниками. Ответы и сообщения демонстрационные, фактическая отправка отсутствует. Контакты Сергея — демонстрационные. XLS выгружается локально.
